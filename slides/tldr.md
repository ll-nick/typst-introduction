# TL;DR

## The good

- Instant incremental compile (millisecond `watch`)
- Actually readable error messages
- One consistent syntax; styling is a real scripting language
- Trivial install — no TeX-distribution archaeology

::right::

## The catch

- Young ecosystem: fewer packages & journal templates
- No mature Word / `.docx` round-trip
- Some publishers are still LaTeX-only

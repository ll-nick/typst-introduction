# Getting started

## Three on-ramps

- **typst.app** — Overleaf-like web IDE, zero install, real-time collaboration
- **CLI** — `typst compile` / `typst watch`, local & reproducible, CI-friendly
- **Editor + tinymist** — VS Code / Neovim, LSP, live preview

::step::

*Pick: web to try it, CLI for reproducibility, editor for daily driving.*
